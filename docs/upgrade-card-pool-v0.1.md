## 8. 数据字段

每张正式卡牌至少配置：

```text
id
name
description
rarity
maxLevel
tags[]
baseWeight
requirements[]
conflicts[]
effect
shopAllowed
shopPriceMultiplier
```

原则：核心卡优先改变玩法，而不是只提供更大的数值。
