# M0.9 — Settlement + Permanent Progress + Save

## 目标

M0.9 完成 V0.1 之前最后一个主要系统闭环：

```text
Main Menu
→ 选择难度
→ Combat Run
→ Base Destroyed / 主动结束 / 测试完成
→ Settlement
→ Gold + Account EXP
→ Account Level / Tech Point
→ Tech Tree
→ Versioned Local Save
→ Main Menu / Next Run
```

M0.9 完成后，不再新增主要系统；后续进入 V0.1 整合、浏览器试玩、数值调优、UI/性能和稳定性阶段。

---

## 1. Scene 结构

Phaser Scene 由单一 CombatScene 扩展为：

```text
MainMenuScene
CombatScene
SettlementScene
```

启动 Scene 为 `MainMenuScene`。

`CombatScene` 只生成本局结果，不直接写永久成长；永久结算统一由 `SettlementScene + PermanentProgressService` 处理。

---

## 2. RunSummary

每局结束生成：

```ts
RunSummary {
  difficulty
  highestWave
  runLevel
  kills
  bossKills
  reason
}
```

结束原因：

```text
BASE_DESTROYED
VOLUNTARY_EXIT
TEST_COMPLETE
```

三种结束方式均使用同一奖励公式。

主动结束属于正常结算，不施加奖励惩罚。

M0.9 移除正式流程中的无结算 `R` 重开；使用：

```text
E / 结束本局
→ Settlement
```

## 3. Settlement Reward V1

奖励继续视为原型值。

### Gold

```text
Gold =
20
+ HighestWave × 6
+ Kills × 0.35
+ BossKills × 25
+ RunLevel × 3
```

之后乘 Difficulty Reward Multiplier。

### Account EXP

```text
AccountEXP =
25
+ HighestWave × 8
+ Kills × 0.5
+ BossKills × 40
+ RunLevel × 4
```

之后乘 Difficulty Reward Multiplier。

结算页显示：

- Difficulty
- Highest Wave
- Run Level
- Kills
- Boss Kills
- Gold
- Account EXP
- Account Level
- Tech Point

## 4. Account Level

```text
Account Level Cap = 100
```

升级需求：

```text
XPToNext = 100 + (AccountLevel - 1) × 30
```

每提升 1 个 Account Level：

```text
+1 Tech Point
```

达到 Lv100 后：

```text
Account EXP 不再继续积累
```

## 5. Permanent Save Schema v1

存档 Key：

```text
rogue-defense.save
```

首版 Schema：

```text
version
accountLevel
accountXp
gold
techPoints
tech
maxDifficultyUnlocked
selectedDifficulty
highWaveByDifficulty[5]
lifetime
```

Lifetime Stats：

```text
runs
kills
bossKills
totalGoldEarned
highestRunLevel
```

### Save 原则

不序列化 Phaser Scene / Enemy / Weapon 实例。

只保存稳定的永久数据模型。

### 版本与坏档处理

```text
SAVE_VERSION = 1
```

Load 时执行：

1. JSON parse；
2. Schema normalize；
3. 数值 Clamp；
4. 缺字段填默认值；
5. 未知/旧版本走 migrate → sanitize；
6. JSON 错误或 localStorage 异常时回退默认存档。

目标是坏档不阻止游戏启动。

## 6. Difficulty

正式保留 5 个难度：

| Difficulty | Enemy HP | Enemy Damage | Settlement Reward |
|---|---:|---:|---:|
| I | ×1.00 | ×1.00 | ×1.00 |
| II | ×1.20 | ×1.10 | ×1.15 |
| III | ×1.45 | ×1.20 | ×1.35 |
| IV | ×1.75 | ×1.35 | ×1.60 |
| V | ×2.10 | ×1.50 | ×2.00 |

M0.9 当前只实现通用数值倍率层。

Difficulty III 的 Elite Affix / 新敌人、IV Boss Ability、V Multi-Boss 仍属于 V0.1 内容整合，不在 M0.9 临时伪造。

### 解锁

初始：

```text
Difficulty I
```

下一难度：

```text
当前最高已解锁难度达到 Wave 100
→ 解锁下一 Difficulty
```

当前 M0.9 测试 Wave 上限仍是 30，因此 W100 解锁属于已完成的数据/规则接口，尚无法在正常原型流程中触发。

## 7. Tech Tree V1

原则：局外成长保持轻量，不取代局内 Build。

### Gold Tech

#### 火力训练

```text
Max Lv10
每级：Run 开局所有武器 Damage +3%
Cost = 80 + CurrentLv × 60 Gold
```

#### 基地加固

```text
Max Lv10
每级：Run 开局 Base MaxHP +5%
Cost = 80 + CurrentLv × 60 Gold
```

#### 战备资金

```text
Max Lv5
每级：Run 开局 Credits +20
Cost = 100 + CurrentLv × 80 Gold
```

### Tech Point Tech

#### 战术加速

```text
Lv1 → 解锁 2×
Lv2 → 解锁 3×
Lv3 → 解锁 4×
Costs = 2 / 4 / 6 TP
```

正式运行初始最大速度因此为 1×。

#### 预备重抽

```text
Max Lv2
每级：Run 开局 +1 Reroll Charge
Costs = 3 / 5 TP
```

## 8. 免费 Tech Respec

主菜单提供：

```text
免费重置全部科技
```

执行时：

- Gold 科技投入全部返还；
- Tech Point 科技投入全部返还；
- 所有科技等级归 0。

不收手续费、不限制次数。

---

## 9. Permanent Tech 在 Combat 的应用

CombatScene 初始化时从 Save 加载：

```text
DamageTraining
→ globalDamageMultiplier 起始值

BaseFortification
→ Base MaxHP

StartingCredits
→ RunState Credits

RerollPrep
→ RunState Reroll Charges

SpeedControl
→ MaxGameSpeed
```

Run 内三选一获得的 Damage / BaseHP 等继续叠加在局外起点之上。

## 11. Settlement → Next Run

结算后提供：

```text
再次开始同难度
返回主界面
```

Settlement 在进入时立即落盘，因此即使玩家之后关闭页面，本局永久奖励也已经保存。
