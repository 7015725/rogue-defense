# M0.2 — Run Progression + First Roguelite Choice

## 目标

M0.2 将 M0.1 的自动战斗原型推进到第一个 Roguelite 闭环：

```text
击杀敌人
→ 自动获得 Run EXP / Credits
→ Run Level Up
→ 战斗完全暂停
→ 三选一
→ 选择成长或跳过换 Credits
→ 恢复战斗
```

## Run EXP

敌人奖励：

- Infantry：5 EXP / 2 Credits
- Wave 10 Boss：100 EXP / 100 Credits

升级公式：

```text
XPToNextLevel = 45 + 15 × (RunLevel - 1)
```

支持一次获得足够 EXP 时连续产生多个待处理升级。

## M0.2 升级池

首批只实现 5 种升级：

1. 强化弹药：所有武器伤害 +10%，最多 10 级
2. 快速循环：所有武器攻击速度 +8%，最多 10 级
3. 加固基地：Base Max HP +12%，并增加等量当前生命，最多 10 级
4. Auto Cannon +1 Lv，最高 Lv10
5. 轻机枪阵地：获得第二套独立武器系统

三选一中同一 Upgrade ID 不重复。

## 跳过

可以不选择任何卡牌，获得局内 Credits：

```text
SkipReward = 25 + 5 × max(0, RunLevel - 2)
```

## LMG Nest

M0.2 第一把随机副武器：

```text
Damage          8
AttackInterval  100 ms (600 RPM)
Range           620
ProjectileSpeed 1000
Magazine        60
Reload          2.4 s
CritChance      5%
CritDamage      ×2
```

LMG 与 Auto Cannon 是两套独立攻击系统：

- 独立索敌
- 独立弹匣
- 独立 Reload
- 独立攻击计时
- 共享 ProjectilePool / DamageSystem
- 共享全局伤害与攻速倍率

## M0.2 Upgrade Director Lite

M0.2 暂不实现完整 Upgrade Director，只实现最小可玩版本：

- 基于合法性过滤候选
- 已满级项目移出池
- LMG 在 Run Lv2 后可出现
- Run Lv3 后提高 LMG 权重
- 如果 Run Lv4 时从未展示过 LMG，则保证该次三选一包含一次 LMG 选择
- 保底只保证展示，不自动给予

## Weapon Level

M0.2 使用临时数值规则验证武器等级结构：

```text
每级 Damage +12%（线性）
每级 AttackSpeed +4%（线性）
```

该数值不是最终 Lv1～10 平衡方案；M0.4 加入 Lv5/Lv10 路线时重新数值化。

## 暂不包含

- Reroll
- 完整 50 张卡池
- LMG Lv5/Lv10 分支
- Boss 商店
- Armor 新敌人
- Air
- Status / Combo
- 局外科技

这些按既定 M0.3～M0.9 路线逐步加入。
