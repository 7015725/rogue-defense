# M0.8 — Boss Shop

## 目标

M0.8 把每 10 Wave 的 Boss Gate 从“只清场”升级为完整的阶段结算节点：

```text
Boss 死亡
→ 清理残余普通敌人 / 护航
→ 战斗完全暂停
→ Boss Shop
→ 购买 / 刷新 / 替换
→ 离开商店
→ 处理待选武器路线 / Run Upgrade
→ 下一 Wave
```

当前原型测试范围扩展到 Wave 30。

## Boss Checkpoint

Boss Gate：

```text
Wave 10
Wave 20
Wave 30
```

Boss 死亡后 `WaveManager` 进入 `waitingForShop`，在显式调用 `resumeAfterShop()` 前不会推进 Wave。

Wave 20：
- Boss + 6 Recon Drone 护航。

Wave 30：
- Boss + 8 Recon Drone 护航。

Boss 死亡后护航和历史残怪统一清理，再进入商店。

离开 Wave 30 商店后结束 M0.8 测试。

## 商店商品槽

固定 5 个商品位。

### Slot 1：后勤位

保证出现以下至少一种：

- Base Heal；
- Weapon Repair。

当前逻辑：
- 有受损武器时，后勤位可能给最严重受损武器维修；
- 否则给 Base 25% 最大生命恢复；
- 后勤仍然需要支付战斗币，不免费。

### Slot 2～5

从合法池中抽取，不允许同屏出现完全相同的商品 ID：

- 全局伤害 +10%；
- 全局攻速 +8%；
- Base MaxHP +12%；
- 已有武器 +1 Lv；
- 新武器 / 满槽换武器；
- 已满足前置但未获得的 Combo；
- Reroll Charge +1。

已满级 / 已获得 / 不合法项目不会生成。

## 刷新

每个 Boss 商店独立维护 RefreshCount：

```text
60
120
240
480
...
```

公式：

```text
RefreshCost = 60 × 2^RefreshCount
```

进入下一个 Boss 商店后重置为 60。

刷新：
- 先支付 Credits；
- 重新生成全部 5 个商品；
- 已经购买产生的实际效果不会回滚；
- 新商品根据刷新后的当前 Build 再做合法性过滤。

## Reroll Charge

Boss Shop 可以购买：

```text
Reroll Charge +1
```

RunState 正式保存：

```text
rerollCharges
```

Level Up 三选一增加“重抽”按钮：
- 有 Charge 时可点击；
- 消耗 1 次；
- 当前 Pending Upgrade 不减少；
- 重新调用 Upgrade Director 生成三张卡。

## 武器耐久

M0.8 补齐正式武器耐久底层：

```text
MaxHP
CurrentHP
Disabled
AutoRepairPerSecond
repair()
repairFull()
takeDamage()
```

初始值：

| 武器 | MaxHP | AutoRepair/s |
|---|---:|---:|
| Auto Cannon | 600 | 15 |
| LMG | 500 | 13 |
| Shotgun | 520 | 13 |
| Sniper | 420 | 11 |
| Auto-GL | 480 | 12 |
| Tesla | 460 | 12 |

规则：

```text
HP > 0
→ 正常工作

HP = 0
→ DISABLED
→ 停止索敌 / 射击
→ 自动维修

恢复至 MaxHP 25%
→ 自动重新上线
```

Boss Shop `Weapon Repair`：

```text
立即恢复该武器至满耐久
```

M0.8 暂未加入 Engineer / Bomber 等主动攻击武器的敌人；耐久底层先建立，供后续直接调用。

## 满槽武器替换

5 个总槽位中：
- Slot 1 Auto Cannon 不可替换；
- 4 个随机槽可替换。

当随机槽已满，Boss Shop 仍可生成当前未拥有的武器。

购买流程：

```text
点击新武器商品
→ 不立即扣 Credits
→ 弹出 Replacement Overlay
→ 玩家选择 1 把随机武器
→ 显示旧路线/专精会丢失的警告
→ 确认后扣 Credits
→ destroy 旧武器
→ 新武器部署到原位置
```

取消替换：
- 不扣钱；
- 商店保持原状态。

### 等级补偿

```text
W10 → Lv2
W20 → Lv4
W30 → Lv6
```

公式：

```text
ReplacementLevel = min(8, ceil(Wave / 10) × 2)
```

新武器：
- 不继承旧武器 Lv5 路线；
- 不继承旧武器 Lv10 专精；
- 继承当前全局属性与已激活 Combo；
- 如果补偿等级达到 Lv5 / Lv10，则立即进入免费路线选择。

## 商店与选择界面优先级

商店内购买 Weapon +1 Lv 或替换武器可能触发 Lv5 / Lv10。

优先顺序：

```text
Boss Shop
→ Weapon Branch Overlay
→ 返回 Boss Shop
```

离开商店后：

```text
Pending Branch
→ Pending Run Upgrade
→ 恢复下一 Wave
```

这样不会出现商店关闭后战斗先跑一帧再弹升级。
