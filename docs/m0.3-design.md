# M0.3 — Five-Weapon Random Pool

## 目标

M0.3 将 M0.2 的“Auto Cannon + LMG”扩展为真正的五武器随机池，使不同局在早期就能形成不同攻击结构。

固定 Slot 1：

- Auto Cannon

随机武器池：

1. LMG Nest
2. Tac-Shotgun Bunker
3. Bolt-Action Sniper
4. Auto-GL
5. Tesla Coil

一局最多获得 4 把随机武器，因此总武器数仍为 5。

## 随机武器保底

M0.3 Upgrade Director Lite：

- Run Lv2 起新武器可进入三选一；
- Run Lv3 起提高新武器候选权重；
- 如果到 Run Lv4 还从未展示过任何随机武器，则该次三选一保证包含 1 个随机武器选择；
- 保底只保证展示，不自动给予；
- 已拥有的武器不会再次出现；
- 已有 4 把随机武器后，Weapon Unlock Pool 关闭；
- 同组三选一已经出现 1 张武器卡时，其他武器卡临时降权，减少三张全是新武器的情况。

## 武器基础形态

### LMG Nest

- 高频实体 Projectile
- Frontmost targeting
- 60 发弹匣 / Reload
- 600 RPM 基准

### Tac-Shotgun Bunker

- 近距离锥形数学判定
- 不创建 12 个真实 Projectile
- 视觉表现为扇形射界
- 目标越靠近，计算命中的弹丸数越多
- 基础 8 发弹匣

### Bolt-Action Sniper

- 超远射程
- 高单发、低射速
- 优先当前 HP 最高的合法目标
- 使用高速实体 Projectile
- 基础高暴击率

### Auto-GL

- 中距离延迟 AOE
- 开火时锁定目标当前落点
- 一段延迟后在固定落点爆炸
- 敌人离开落点后可以躲开，因此普通榴弹可能打空
- 爆炸范围使用数学距离判定

### Tesla Coil

- 短射程
- 不使用弹匣
- Primary target 采用 Frontmost
- 命中后向附近目标继续连锁
- M0.3 使用轻量 300ms Stun 验证控制手感
- 完整 StatusEffectSystem 仍延后到 M0.7

## Weapon Mode

M0.3 WeaponDefinition 增加：

```text
mode:
- projectile
- shotgun
- grenade
- tesla

targetingRule:
- frontmost
- highest-hp
```

并为特殊武器预留：

- coneAngleDeg
- pelletCount
- aoeRadius
- impactDelayMs
- chainCount
- chainRange
- stunMs

## M0.3 暂不做

- Lv5 / Lv10 路线
- 随机副武器自身等级升级卡
- Burn / Freeze / ArmorBreak 等正式状态
- Combo
- Air targeting
- Boss Shop
- 武器替换

这些继续按 M0.4～M0.8 路线推进。
