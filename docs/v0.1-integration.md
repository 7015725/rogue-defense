# V0.1 Integration — Endless Wave / Wave 100

## 目标

V0.1 Integration 不再新增主要系统，而是把 M0.1～M0.9 的功能原型收口为真正可持续运行的一局游戏。

本阶段第一批集成重点：

```text
固定 Wave1～30 测试表
↓
正式 Endless Wave Director
↓
Population Budget
↓
Wave HP / Damage Scaling
↓
每 10 Wave Boss Gate + Boss Shop
↓
Wave 100 难度解锁里程碑
↓
Wave 101+ 继续无尽
```

Wave 100 **不是本局终点**。

玩家击杀 Wave 100 Boss、完成 Boss Shop 后进入 Wave 101；只有 Base Destroyed 或玩家主动结束才进入结算。

## Population Budget

单位人口成本：

| Enemy | Population Points |
|---|---:|
| Infantry | 1.0 |
| Flying | 1.5 |
| Heavy | 2.5 |

Boss 不进入普通 Wave Budget。

基础预算使用分段曲线：

```text
Wave 1～10
Budget = 8 + (Wave - 1) × 1.6

Wave 11～20
Budget = 22.4 + (Wave - 10) × 0.8

Wave 21～50
Budget = 30.4 + (Wave - 20) × 0.5

Wave 51+
Budget = 45.4 + (Wave - 50) × 0.3
```

最终取整。

### Reinforced Wave

每 5 Wave 且不是 Boss Wave：

```text
Wave 5 / 15 / 25 / 35 / ...
Population Budget ×1.10
```

UI 显示 `REINFORCED`。

## 敌人构成

### Heavy

- Wave 1～5：无 Heavy。
- Wave 6 起出现。
- W6 / W7 / W8 / W9 保留 M0.5 的早期重甲压力：最低 1 / 2 / 2 / 3。
- 后续使用预算比例 + 最小数量共同决定。
- Heavy Population Cost = 2.5。

Armor 仍然是敌人身份：

```text
Heavy Armor = 100
```

**Armor 不随 Wave 自动增长。**

### Flying

- Wave 1～19：无普通 Flying。
- Wave 20 Boss Gate 首次出现空中护航。
- Wave 21+ 普通 Wave 至少混入 1 个 Flying，并随 Wave 逐步提高数量。
- Flying Population Cost = 1.5。

## Boss Gate

所有 10 的倍数都是 Boss Gate：

```text
W10
W20
W30
...
W100
W110
...
```

流程：

```text
进入 Boss Wave
→ 停止普通 Wave 计时推进
→ Boss + 合法护航生成
→ 必须击杀 Boss
→ 清理普通残敌/护航
→ Boss Shop 完全暂停
→ 玩家显式离店
→ Wave +1
```

### Air Escort

```text
W10 = 0
W20 = 6
W30 = 8
W40 = 10
...
最高 20
```

## Enemy HP Scaling

```text
index = Wave - 1

HP Multiplier
=
(1 + 0.055 × index)
× 1.018^index
```

参考：

| Wave | HP Multiplier |
|---:|---:|
| 1 | ×1.00 |
| 10 | ×1.76 |
| 20 | ×2.87 |
| 30 | ×4.35 |
| 50 | ×8.86 |
| 80 | ×21.88 |
| 100 | ×37.69 |

然后再乘 Difficulty HP Multiplier。

例如 Difficulty II W100：

```text
Wave HP ×37.69
× Difficulty 1.20
```

## Enemy Damage Scaling

```text
index = Wave - 1

Damage Multiplier
=
(1 + 0.035 × index)
× 1.012^index
```

参考：

| Wave | Damage Multiplier |
|---:|---:|
| 1 | ×1.00 |
| 10 | ×1.46 |
| 20 | ×2.09 |
| 30 | ×2.85 |
| 50 | ×4.87 |
| 80 | ×9.66 |
| 100 | ×14.54 |

然后再乘 Difficulty Damage Multiplier。

普通敌人的主要后期压力仍应来自：

```text
更多敌人
+
更高 HP
+
上一 Wave 残怪
+
更高漏怪惩罚
```

而不是普通怪突然一击秒杀 Base。

## 局内 EXP / Combat Credits Scaling

为了让 W100 Run Level 落入既定目标区间：

```text
Reward Multiplier
=
1 + (Wave - 1) × 0.01

上限 ×2.5
```

参考：

```text
W1   ×1.00
W20  ×1.19
W50  ×1.49
W80  ×1.79
W100 ×1.99
```

只影响：

- Run EXP；
- Combat Credits。

不直接增加 Permanent Gold / Account EXP；永久奖励仍由 Settlement 统一计算。

按当前预算与基础敌人奖励粗算，完整击杀至 W100 的总 Run EXP 会把玩家带到约 **Run Lv65**，处于既定 W100 目标 Lv58～70 内。

## Wave 100 / Difficulty Unlock

M0.9 已实现：

```text
RunSummary.highestWave >= 100
AND
本局 Difficulty == 当前最高已解锁 Difficulty
AND
Difficulty < V
→ 解锁下一 Difficulty
```

V0.1 Integration 移除原来的：

```text
highestWave = min(30, currentWave)
```

改为保存真实最高 Wave。

因此：

```text
Difficulty I 达 W100 → 结算后解锁 II
Difficulty II 达 W100 → 解锁 III
...
Difficulty IV 达 W100 → 解锁 V
Difficulty V 不再继续解锁
```

玩家可以在 W100 后继续当前局；解锁在本局最终结算时统一写入 Save。
