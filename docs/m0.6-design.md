# M0.6 — Air + Anti-Air

## 目标

M0.6 引入独立空中目标域，让武器组合第一次面对“目标合法性”压力，而不是所有武器都能攻击所有敌人。

核心原则：

- Ground 与 Air 是独立 TargetDomain；
- 空军使用独立 AirPath 视觉轨迹；
- 武器目标域由 WeaponDefinition 声明；
- TargetingSystem 统一过滤目标域；
- AOE / Chain / Cone 同样必须遵守目标域，不能绕过对空限制；
- 固定 Auto Cannon 始终可以对空，因此不会发生纯 RNG 导致完全无法处理 Air 的情况；
- 副防空仍有结构性展示保护，但只保证出现选择，不自动给予。

## TargetDomain

```text
GROUND
AIR
```

`Targetable` 新增：

```ts
readonly domain: TargetDomain
```

`WeaponDefinition` 新增：

```ts
readonly targetDomains: readonly TargetDomain[]
```

## 武器对空权限

| 武器 | Ground | Air |
|---|---|---|
| Auto Cannon | ✓ | ✓ |
| LMG Nest | ✓ | ✓ |
| Bolt-Action Sniper | ✓ | ✓ |
| Tac-Shotgun Bunker | ✓ | ✗ |
| Auto-GL | ✓ | ✗ |
| Tesla Coil | ✓ | ✗ |

UI 中支持 Air 的武器会显示 `AA` 标签。

## Recon Drone

第一种 Flying Enemy：

```text
HP             60
Armor          0
ArmorGrade     UNARMORED
Domain         AIR
MoveSpeed      90
AttackDamage   8
AttackInterval 0.8 s
EXP            7
Credits        3
```

视觉：

- 青色方形旋转 45°，作为原型无人机；
- 显示 `AIR` 标签；
- 不使用 Ground Lane；
- 使用独立 Air Lane Offset 与横向摆动轨迹；
- 最终仍向底部 Base 汇聚并攻击基地。

## AirPath

Ground Path 继续使用：

```text
[-160, -80, 0, 80, 160]
```

AirPath 使用更宽的入口：

```text
[-260, -130, 0, 130, 260]
```

空军向下推进时带轻量横向摆动，并逐渐向 Base 中央收束。

逻辑危险度仍统一使用：

```text
pathProgress: 0 → 1
```

因此 Frontmost Targeting 不需要为 Air 写另一套规则。

## Wave 10 / 20 Boss Gate

M0.6 将测试范围从 Wave 10 扩展到 Wave 20。

### Wave 10

```text
Wave 1～9
→ Wave 10 Boss Gate
→ Boss 击杀
→ 清理残余普通敌人
→ Wave 11
```

不再像旧原型一样在 Wave 10 直接结束。

### Wave 20

空军正式从 Wave 20 开始出现。

为了在 M0.6 范围内实际验证 Air，Wave 20 Boss Gate 使用：

```text
1 × Boss
+
6 × Recon Drone Escort
```

Boss 击杀后清理残余护航单位，并结束 M0.6 测试。

这满足：

> Wave 1～19 不出现 Flying；Wave 20+ 才开始出现 Flying。

## Wave 11～19 Ground Pressure

M0.6 继续增加 Infantry / Heavy 数量，但 Wave 11～19 仍全部是 Ground，确保首次 Air 暴露点保持在 Wave 20。

## Anti-Air Upgrade Protection

有效副防空定义：

```text
LMG
Sniper
```

Auto Cannon 不计入“副防空保护是否已满足”，因为它本身固定存在，只承担最低安全线。

Director 规则：

```text
Wave < 15
正常武器权重

Wave 15+
如果没有 LMG / Sniper：
LMG / Sniper Unlock Weight ×3

Wave 18+
如果仍没有副防空
且此前从未展示过有效副防空选项：
下一次升级三选一强制包含 LMG 或 Sniper
```

保底只保证出现选项，不自动解锁。

如果玩家主动拒绝防空选项，应承担 Wave 20 空军压力。

## AOE / Chain 合法性

M0.6 明确规定：

- Shotgun Cone 只命中 WeaponDefinition 允许的 Domain；
- Auto-GL 爆炸只伤 Ground；
- Tesla Chain 不会从 Ground 跳到 Air；
- Tesla Radial 不会伤 Air；
- Split Target / MultiShot 选择额外目标时也必须遵守相同 Domain。

所有逻辑统一通过 `TargetingSystem.canTarget()` 与 Domain-aware Targeting API。

## 暂不包含

- Flying Bomber 行为；
- Suicide Air；
- 专用 AA Weapon；
- 空中 Armor 类型；
- 地雷防空升级；
- Air-only Targeting Priority；
- 正式 StatusEffect / Combo。

这些后续按完整敌人库和 M0.7+ 系统继续扩展。
