# M0.4 — Weapon Lv1–10 + Lv5/Lv10 Routes

## 目标

M0.4 将 M0.3 的“不同武器组合”推进到真正的局内武器成长：

```text
Weapon Lv1
→ Lv2～4 数值成长
→ Lv5 免费选择 α / β / γ 路线
→ Lv6～9 延续路线成长
→ Lv10 免费选择路线专精
→ 后续 Weapon Core Pool 接口开放
```

路线选择不消耗额外 Run Level Up，也不能跳过。

## 升级流程

普通三选一现在可以出现任意已拥有武器的 `+1 Lv`：

```text
Auto Cannon +1 Lv
LMG Nest +1 Lv
Tac-Shotgun Bunker +1 Lv
Bolt-Action Sniper +1 Lv
Auto-GL +1 Lv
Tesla Coil +1 Lv
```

达到 Lv5 / Lv10 时：

1. 当前升级选择结算；
2. 战斗继续保持暂停；
3. 立即弹出该武器路线选择；
4. 路线选择完成后，再处理下一次 Pending Upgrade。

Lv4→5、Lv9→10 的武器升级候选获得轻度权重提升，仍然不是强制给予。

## Lv1～10 基础数值

M0.4 继续沿用原型数值：

```text
每级 Damage +12%（线性）
每级 AttackSpeed +4%（线性）
```

这仍是原型验证值；正式平衡阶段会改为每把武器独立成长表。

## 路线效果架构

路线数据独立位于：

```text
src/weapons/WeaponProgression.ts
```

每个 Lv5 / Lv10 选择可以组合修改：

- Damage
- Attack Speed
- Range
- Projectile Speed
- Magazine
- Reload
- Crit Chance / Crit Multiplier
- Armor Penetration
- Weapon Mode
- Targeting Rule
- Shotgun Cone / Pellet Count
- Grenade AOE / Burst Count
- Tesla Chain / Chain Range / Stun
- Multi Shot / Split Targets
- Same-target damage ramp

`Weapon` 只读取合并后的最终 BranchEffect，因此未来可以继续增加分支而不把路线逻辑写死在 `CombatScene`。

- α 长管精确化：射程、伤害、弹速提高，射速降低。
- β 双联自动炮：一次双发，降低单发伤害。
