# M0.5 — Armor + Heavy Armored Enemy

## 目标

M0.5 第一次让“武器选择 / 路线选择”与敌人防御类型产生明确克制关系。

核心原则：

- Armor 是敌人身份属性，不随 Wave 无限成长；
- 普通直接伤害统一经过 ArmorSystem；
- 穿甲只降低本次伤害计算使用的有效 Armor；
- ArmorBreak 是目标上的临时减甲状态接口；
- Burn 等未来 DOT 是否无视 Armor 由对应伤害类型决定，留到 M0.7。

## Armor Grade

玩家可见等级：

```text
UNARMORED
LIGHT
MEDIUM
HEAVY
```

当前 M0.5：

| 敌人 | Armor | Grade |
|---|---:|---|
| Infantry | 0 | UNARMORED |
| Heavy Armored | 100 | HEAVY |
| Wave 10 Boss | 20 | LIGHT |

MEDIUM 已进入数据结构，但当前测试敌人暂未使用。

## Armor 公式

```text
EffectiveArmor = max(0, Armor - ArmorPenetration)
DamageReduction = EffectiveArmor / (EffectiveArmor + 100)
FinalDamage = RawDamage × (1 - DamageReduction)
```

典型结果：

| Armor | Reduction |
|---:|---:|
| 0 | 0% |
| 20 | 16.7% |
| 50 | 33.3% |
| 100 | 50% |
| 200 | 66.7% |

因此 Heavy Armor=100 时，无穿甲直接伤害约减半。

## Heavy Armored Enemy

```text
HP             220
Armor          100
ArmorGrade     HEAVY
MoveSpeed      36
AttackDamage   22
AttackInterval 1.5 s
EXP            14
Credits        6
```

定位：

- 慢速；
- 高 HP；
- 高 Armor；
- 用于检验 HeavyHit / ArmorPen / Sniper / Slug 等路线价值。

Heavy 会分散插入 Wave，而不是全部集中在最后生成。

## 已有穿甲路线

M0.4 已实现并在 M0.5 开始具备实际克制价值：

- Auto Cannon α → Lv10 穿甲弹：Armor Penetration +50
- LMG α → Lv10 钨芯弹：Armor Penetration +40
- Shotgun β 独头弹：基础 Armor Penetration +30
- Shotgun β → Lv10 钨芯独头弹：额外 +50
- Sniper α：Armor Penetration +40
- Sniper α → Lv10 重型穿甲弹：额外 +70

ArmorPen 与当前 Armor 直接参与 DamageSystem 计算。

## ArmorBreak 接口

Targetable 新增：

```ts
applyArmorBreak(amount, durationMs)
```

Enemy 内部保存：

```text
baseArmor
armorBreakAmount
armorBreakTimerMs
```

读取 `enemy.armor` 时返回临时破甲后的有效基础护甲。

M0.5 暂不新增破甲卡牌，接口留给：

- M0.7 震荡破甲 Combo；
- 后续武器核心；
- Boss / 特殊机制。

## UI


主 HUD 在有 Heavy 存活时显示：

```text

```

## 架构

新增：

```text
src/systems/ArmorSystem.ts
```

DamageSystem 不再自己复制 Armor 公式，而统一调用 ArmorSystem。

## 暂不包含

- Armor 随 Wave 增长
- 永久 Armor Shred
- 元素抗性
- Shield
- Burn 无视 Armor 的正式伤害类型
- AT Gun 的护甲等级倍率

这些在对应后续系统中加入。
