# M0.7 — Status + Combo

## 目标

M0.7 将 M0.4～M0.6 中分散的临时控制逻辑统一到正式 `StatusEffectSystem`，并让首批 4 个跨武器 Combo 作为局内稀有升级进入三选一。

核心事件链：

```text
Weapon / Projectile / AOE
→ DamageSystem
→ ArmorSystem
→ Direct Damage
→ ComboSystem
→ Status Applications
→ Target StatusEffectSystem
```

Combo 在本次命中新状态写入之前结算，因此：

- Tesla 第一次命中只负责建立 `CHARGED / STUN`；
- 后续 Lightning 命中才可触发 Overload；
- Explosion 可以结算此前由 Shotgun 建立的 Burn；
- Sniper / Heavy Hit 可以利用此前存在的 Hard Control。

## StatusEffectSystem

正式状态类型：

```text
BURN
SLOW
FREEZE
STUN
ARMOR_BREAK
CHARGED
SUPPRESSED
```

`SUPPRESSED` 是烟幕的攻击速度压制状态，用于补充既定 Smoke 机制。

### Burn

Shotgun Lv5 α 龙息弹来源：

```text
Duration       5s
MaxStacks      3
TickInterval   1s
Refresh        命中刷新持续时间
Damage         随本次命中强度生成
Armor          DOT 直接扣 HP，不经过 ArmorSystem
```

同一目标再次中 Burn：

- 层数增加，最多 3；
- 持续时间刷新；
- 当前 Burn Tick 强度取较高值。

### Slow / Freeze

Auto-GL Lv5 α 温压弹：

```text
Slow = 30%
Duration = 4s
```

Slow 在当前原型中可以累积：

```text
累计 Slow >= 65%
→ 清除 Slow
→ Freeze 1s
```

最大 Slow 为 75%。

Freeze 属于 Hard Control。

### Stun

Tesla 基础攻击：

```text
Stun = 300ms
```

路线中的 `stunMsBonus` 全部通过统一 StatusEffectSystem 叠加到实际 Stun 时长。

Auto-GL α → Lv10 冲击波：

```text
Stun +500ms
```

### ArmorBreak

不再由 Enemy 自己维护独立 timer。

统一状态：

```text
ARMOR_BREAK
magnitude = 临时降低 Armor 的数值
duration  = 状态持续时间
```

当前首个正式来源是 `震荡破甲` Combo：

```text
ArmorBreak 35
Duration 4s
```

### Charged

Tesla 每次有效 Lightning 命中后：

```text
Charged 2.5s
```

用于 Overload Combo。

### Suppressed / Smoke

Auto-GL Lv5 γ 烟幕协议：

```text
Enemy AttackSpeed -40%
Duration 6s
```

实现方式：目标攻击速度倍率降低到 60%，即攻击间隔相应变长。

## Boss Hard Control Resistance

Boss 不做硬控免疫。

每次应用 STUN / FREEZE：

```text
当前控制持续时间 × (1 - ControlResistance)
```

规则：

```text
初始 Resistance = 0
每次 Hard Control 后 +15%
最大 = 75%
最低仍保留 25% 原始控制持续时间
脱离连续控制后每秒衰减 5 个百分点
```

这样控制 Build 对 Boss 仍有效，但无法无限锁死。

## Status UI

Enemy 顶部显示轻量状态标签：

```text
BURN×2 · SLOW
STUN · BREAK
CHARGED
SMOKE
```

用于原型阶段快速验证状态是否真正生效。

## 首批 Combo

Combo 不是默认机制，必须通过局内三选一获得。

M0.7 Combo 卡从 `Run Lv8+` 开始进入候选池，并要求基本武器前置。

### 1. 爆燃协议 / DETONATION

前置：

```text
Shotgun + Auto-GL
```

触发：

```text
Burn + Explosion
```

效果：

```text
按剩余 Burn Tick 潜力的 35% 立即造成额外伤害
消耗 1 层 Burn
```

### 2. 震荡破甲 / CONCUSSIVE_BREAK

前置：

```text
Tesla + (Sniper 或 Shotgun)
```

触发：

```text
Hard Control + Heavy Hit
```

Heavy Hit 当前来源：

- Sniper；
- Shotgun β 独头弹。

效果：

```text
ArmorBreak 35 / 4s
```

### 3. 电力过载 / OVERLOAD

前置：

```text
Tesla
```

触发：

```text
Charged + Lightning
```

效果：

```text
目标追加本次有效伤害的 35%
附近 260 范围内最近的同 Domain 目标再受到同额 Overload Damage
```

因为 Combo 在新 Charged 写入前判定，所以 Tesla 第一次命中不会自行触发 Overload。

### 4. 控制处决 / CONTROL_EXECUTION

前置：

```text
Tesla + Sniper
```

触发：

```text
Hard Control + Sniper Critical
```

效果：

```text
追加本次有效伤害的 75%
```

## Combo Director

三选一新增：

```text
UpgradeKind = combo
```

规则：

- Run Lv8 前不出现；
- 必须满足基本武器组合；
- 已获得 Combo 永久移出本局候选池；
- Combo 基础权重 = 4；
- 同一组三选一已经出现一个 Combo 后，其他 Combo 权重 ×0.35；
- 不会自动授予 Combo。

## Weapon 接入

所有攻击类型都通过 `DamageContext` 携带：

```text
sourceWeaponId
tags[]
statusApplications[]
comboTargets[]
enabledCombos[]
```

因此：

- Projectile；
- Shotgun Cone；
- Grenade AOE；
- Tesla Chain；
- Tesla Radial；

使用完全相同的状态 / Combo 管线。

## 暂不包含

M0.7 不实现：

- Poison；
- Boss 独有状态免疫表；
- 大规模 Combo 库；
- 元素抗性；
- 状态专属 UI 图标美术；
- Combo 进化；
- 通用机制卡完整 50 张池全部落地。

这些在后续卡池扩展与内容阶段继续增加。
